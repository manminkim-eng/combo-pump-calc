```

```

| 단계 | 처리 |
|---|---|
| 배율 해제 | `rpt-inner` 의 `transform` 초기화 — 모바일 축소배율이 이미지에 박히는 것 방지 |

| 제외 | `.no-print` (버튼·힌트) |
| 2매 이상 | **저장 시트** 표시 — 브라우저가 연속 자동 다운로드를 차단하므로 페이지별 버튼 제공 |
